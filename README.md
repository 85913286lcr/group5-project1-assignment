# group5-project1-assignment
Group collaboration for project 1

Rachelle used Pandas to clean and validate the complete dataset, standardise key fields, correct salary issues, remove invalid and duplicate records, and export the final `jobs_clean.csv` for team analysis.The cleaning process reduced the original 1,048,585 records to 140,506 valid, unique job postings with complete and consistent salary data for analysis.

Rachelle selected the topic **“Salary Benchmark by Position Level”**, focusing on the business question: **“How do salaries differ by position level?” Using the team’s cleaned dataset of **140,506 valid and unique job postings**, she used Pandas to validate the required columns, examine data quality, calculate job-posting counts, and compare median salaries, average salaries, and salary ranges across nine position levels. The results will be presented in an interactive Streamlit dashboard to help HR and recruitment teams understand salary differences by seniority.
